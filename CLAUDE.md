# BM Sender — еженедельные отчёты родителям

Автоматизация подготовки еженедельных отчётов родителям участников трека
BizMission по итогам кураторских Zoom-встреч (саммари из Fireflies) и
публикации черновиков в Telegram-чат кураторов после подтверждения
пользователя.

**Ничего не отправляется в Telegram без явного "ок" от пользователя в чате.**

## Настройка (один раз)

1. Скопировать `.env.example` → `.env`, заполнить:
   - `FIREFLIES_API_KEY` — Fireflies → Settings → Developer Settings.
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather.
   - `TELEGRAM_CHAT_ID` — chat_id группы кураторов. Чтобы узнать: добавить
     бота в группу, написать туда любое сообщение, затем
     `python telegram_client.py whoami`.
2. `pip install -r requirements.txt`.

## Источник списка участников

Гугл-таблица `GOOGLE_SHEET_ID` (без заголовков, 3 колонки: Участник (Фамилия
Имя) | Родитель(и) | Мессенджер). Мессенджер — только для шапки сообщения
куратору; фактическая доставка всегда через один и тот же Telegram-чат
кураторов, дальше куратор сам пересылает родителю в нужный мессенджер.

У Claude Code уже есть доступ к Google Drive MCP — таблицу читает сам агент
(`read_file_content` по `GOOGLE_SHEET_ID`), отдельных Google-credentials не
нужно. Полученный markdown прогнать через `roster.parse_roster_markdown` и
закэшировать `roster.save_roster(...)`, чтобы дальше пользоваться
`roster.load_roster()`.

## Еженедельный процесс — ручной запуск (по команде пользователя, например
«сделай отчёты за эту неделю»)

1. Обновить `roster.json` (см. выше) — актуальный список участников
   (`roster.load_roster()`, читает CSV-экспорт таблицы напрямую).
2. Определить период: по умолчанию последние 7 дней (сегодня минус 7 дней —
   сегодня), либо период, который явно укажет пользователь.
3. Для каждого участника:
   `fireflies_client.find_meetings_for(participant.fio, date_from, date_to)`.
   - Если встреч нет или у всех найденных встреч пустое саммари — не
     выдумывать отчёт, отметить участника отдельно в сообщении пользователю
     ("по Х встреч на этой неделе не было / саммари ещё не готово").
   - Если встреч несколько — использовать все, синтезировать один отчёт.
4. Написать черновик отчёта для каждого участника со встречами, строго в
   стиле образца (см. ниже). Основа текста — `overview`/`bullet_gist` из
   Fireflies, не выдумывать детали, которых нет в саммари.
5. Показать пользователю в чате все черновики целиком (участник → текст),
   попросить подтверждение/правки.
6. После подтверждения — для каждого одобренного отчёта:
   `telegram_client.send_message(header + "\n\n" + report_text)`, где
   `header = f"{participant.fio} — {participant.parents} — {participant.messenger}"`.

## Автоматический еженедельный запуск (пятница 11:00 МСК, cron)

Тот же процесс, что и ручной (шаги 1–4 выше), но **без шага подтверждения** —
пользователь явно попросил публиковать сразу в группу кураторов без
предварительного показа черновиков. Отличия:

- Период всегда — последние 7 дней от момента запуска.
- Участников без встреч/без готового саммари за неделю — просто пропустить
  молча (без отчёта и без отдельного уведомления), не отправлять пустые или
  придуманные отчёты.
- Для каждого участника с реальным содержанием сразу вызвать
  `telegram_client.send_message(header + "\n\n" + report_text)`.
- Доступ к таблице — публичный CSV-экспорт (`roster.py`), доступ к Fireflies
  и Telegram — через `.env`, интерактивных MCP-инструментов в cron-агенте
  может не быть, поэтому весь пайплайн должен быть самодостаточен (см.
  `roster.py`, `fireflies_client.py`, `telegram_client.py`).

## Стиль отчёта (образец)

```
Стас, Елена, здравствуйте!

➡️ Отчёт по треку Евы за период 15.06–21.06

🔸 Синхронизация с куратором

<2–4 абзаца свободным текстом: что делали на встрече, какие темы разобрали,
конкретные наблюдения о поведении/реакциях участника, что особенно хорошо
получилось>

🔸 Дальнейшие шаги

<1–2 абзаца: что запланировано на следующую встречу, договорённости>
```

Правила:
- Обращение — по именам из колонки «Родитель(и)» (например «Стас, Елена,
  здравствуйте!» для «Стас и Елена»; «Александр, здравствуйте!» для
  одного имени).
- Заголовок отчёта — по имени участника (обычно только имя, не фамилия),
  период — `ДД.ММ–ДД.ММ` (даты периода прогона).
- Тон — тёплый, конкретный, без канцелярита; хвалить искренне и по делу,
  избегать общих фраз без опоры на саммари встречи.
- Использовать эмодзи-разделители 🔸 ровно как в образце (не изобретать
  новые).
