# BM Sender — Apps Script версия

Отдельный самостоятельный скрипт (не привязан к таблице участников — читает
её по ID через `openById`, доступ по ссылке уже открыт, поэтому подойдёт
любой ваш Google-аккаунт, не обязательно тот, что владеет таблицей).

## Настройка (один раз)

1. Откройте **script.google.com** → **New project** (под своим обычным
   Google-аккаунтом).
2. Удалите весь код-заглушку в `Code.gs`, вставьте туда содержимое файла
   [`Code.gs`](Code.gs) из этой папки.
3. Назовите проект, например, «BM Sender».
4. Настройте часовой пояс проекта на Москву:
   - слева иконка **Project Settings** (шестерёнка) → включите галочку
     **«Show appsscript.json manifest file in editor»**.
   - откроется файл `appsscript.json` слева в списке файлов → откройте его,
     найдите/добавьте строку `"timeZone": "Europe/Moscow"`, сохраните.
5. Добавьте секреты: **Project Settings** → раздел **Script Properties** →
   **Add script property**, добавить четыре штуки:
   - `FIREFLIES_API_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `OPENROUTER_API_KEY` (ключ с openrouter.ai — там же нужно будет
     пополнить баланс, копейки за 5-8 коротких отчётов в неделю)
6. В редакторе кода, наверху есть выпадающий список функций — выберите
   **`weeklyRun`** и нажмите **Run** (▶). Google спросит разрешения
   (доступ к внешним URL и к таблице по ссылке) — подтвердите.
   - Если правил на этой неделе ещё нет ни у кого — в логе (**View → Logs**)
     будет "Пропущены: ...". Это нормально для проверки.
   - Если что-то пошло не так — ошибка появится там же, в логе.
7. Как только `weeklyRun` отработал вручную без ошибок — настройте
   автозапуск: в выпадающем списке функций выберите **`createWeeklyTrigger`**
   и нажмите **Run** один раз. Это поставит еженедельный запуск на пятницу,
   ~11:00 (часовой пояс проекта — Europe/Moscow, см. шаг 4).
   - Проверить триггер можно слева, иконка **Triggers** (часы).

## Отличие от Python-версии в d:\BM\Sender

- Работает на серверах Google — не зависит от этого компьютера и не
  упирается в сетевые ограничения, как облачный Claude Code routine.
- Текст отчёта пишет не Claude Code (меня тут нет), а прямой вызов Claude
  через OpenRouter с тем же стилем (сокращённая версия правил из CLAUDE.md
  зашита в `STYLE_GUIDE` внутри `Code.gs`) — значит, нужен `OPENROUTER_API_KEY`
  и баланс на openrouter.ai (копейки за 5-8 коротких отчётов в неделю).
- Секреты хранятся в Script Properties Google — не в файле, не в git.

## Рекомендация по переходу

Сначала протестируйте (шаг 6-7) параллельно с уже работающим Windows Task
Scheduler, сравните качество отчётов. Когда убедитесь, что всё ок — можно
отключить задачу в Task Scheduler на этом компьютере, чтобы не было
дублей по пятницам.
